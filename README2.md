# AI Security & Agentic Engineering Labs 🛡️🤖

Hands-on repository demonstrating local LLM execution, custom agentic harness engineering, OWASP Top 10 for LLM mitigations, and MITRE ATLAS threat modeling.

## 📂 Repository Contents & Proof of Work

- **`01-local-llm-deployment/`**: PowerShell automation scripts (`ollama_setup.ps1`) for local model hosting (Ollama, LM Studio), offline inference management, and token performance benchmarking.
- **`02-agentic-harnesses/`**: Custom Python implementation of ReAct loops (`react_agent.py`), tool-use integrations, and Model Context Protocol (MCP) server components.
- **`03-genai-owasp-mitigations/`**: Input validation and defensive guardrails (`prompt_injection_defense.py`) targeting OWASP GenAI Top 10 vulnerabilities, mapped to AWS/Azure cloud security controls.
- **`04-mitre-atlas-threats/`**: Threat modeling documentation (`threat_model_atlas.md`) detailing adversarial machine learning risks including data poisoning and model extraction.
- **`05-advanced-reasoning-agents/`**: Autonomous self-reflection loops (`reflexion_loop.py`) featuring iterative self-critique, verification, and state-memory management.

## 🚀 Key Competencies
- Local Open-Weight LLM Inference & PowerShell Automation
- OWASP GenAI Risk Assessment & Guardrail Engineering
- Adversarial AI Threat Modeling (MITRE ATLAS)
- ReAct Agent Harnesses & Tool-Calling Integration
